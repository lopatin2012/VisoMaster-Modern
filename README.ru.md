## Что это

VisoMaster-Modern — настольное приложение для ИИ-**замены и редактирования лиц** на изображениях, видео
и веб-камере. Включает несколько моделей сваппера, восстановления лиц и улучшения кадров (а также
модели DeepFaceLab DFM), маскирование по частям лица, редактор лица на базе LivePortrait, эмбеддинги
лиц, видео-маркеры и вывод в виртуальную камеру.

## Возможности

### 🔄 **Замена лиц (Face Swap)**
- Поддержка нескольких моделей сваппера
- Совместимость с моделями, обученными в DeepFaceLab (DFM)
- Продвинутая замена нескольких лиц с маскированием отдельных частей
- Маскирование перекрытий (DFL XSeg Masking)
- Работает со всеми популярными детекторами лиц и ключевых точек
- Восстановление выражения лица: переносит мимику на заменённое лицо
- Восстановление лица: поддержка популярных моделей апскейла и улучшения

### 🎭 **Редактор лица (модели LivePortrait)**
- Ручная настройка выражений и поз для разных частей лица
- Тонкая подстройка цвета волос, бровей и губ через RGB

### 🚀 **Прочие возможности**
- **Живое воспроизведение**: результат виден в реальном времени до сохранения
- **Эмбеддинги лиц**: несколько исходных лиц для лучшей точности и схожести
- **Живой свап через веб-камеру**: трансляция в виртуальную камеру для Twitch, YouTube, Zoom и т.д.
- **Удобный интерфейс**, в т.ч. русский язык
- **Видео-маркеры**: настройки для отдельных кадров
- **Поддержка TensorRT**
- **И многие другие возможности** 🎉

## Требования

- Windows 10/11 (Linux тоже работает), актуальный драйвер NVIDIA.
- **Python 3.11** — не используйте 3.14 (нет колёс для закреплённого набора).
- Проект рассчитан на современные GPU (RTX 40/50, `sm_90`/`sm_120`). Устаревшие сборки CUDA 11.8/12.4 не поставляются.
- ~15 ГБ свободного места под модели и кэши.

## Установка (Windows, venv)

```sh
git clone https://github.com/lopatin2012/VisoMaster-Modern.git
cd VisoMaster-Modern
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements_cu129.txt
```

## Модели и ffmpeg

1. Скачайте модели:
   ```sh
   .venv\Scripts\python.exe download_models.py
   ```
2. Скачайте бинарные файлы со страницы
   [visomaster-assets](https://github.com/visomaster/visomaster-assets/releases/tag/v0.1.0_dp)
   и скопируйте их в папку `dependencies/` (архивы «Source code» скачивать **не** нужно).
   Встроенный `dependencies\ffmpeg.exe` определяется автоматически, отдельная установка ffmpeg не требуется.

## Запуск

```sh
.venv\Scripts\python.exe main.py
```

или двойной клик по **Start.bat** (использует `.venv`, если он есть). Дополнительная диагностика:

```sh
.venv\Scripts\python.exe main.py --profile   # вывод времени по стадиям в консоль
```

## Язык интерфейса

Переключение: **Settings → Appearance → Language** (`English` / `Русский`). Язык применяется сразу,
без перезапуска, и сохраняется между запусками.

## Опционально: TensorRT

TensorRT установлен, но по умолчанию используется провайдер **CUDA**. В **Settings → Providers Priority**
можно выбрать *TensorRT*; при первом запуске движки соберутся в `tensorrt-engines/` (долго один раз,
далее из кэша). На встроенных моделях CUDA показал ту же скорость, поэтому TensorRT — опция.

## Обновление

```sh
scripts\update_cu129.bat
```
подтягивает свежий `main` (hard reset) и переустанавливает зависимости.

## Решение проблем

- Проблемы с CUDA — обновите драйвер NVIDIA.
- Нет моделей — проверьте, что файлы лежат в нужных подпапках `model_assets/`.
- Запись/экспорт требуют ffmpeg — встроенный `dependencies\ffmpeg.exe` находится автоматически.
