VisoMaster-Modern

AI face swapping and editing for images, videos and webcam streams. A community fork of VisoMaster, modernized for recent NVIDIA GPUs (CUDA 12.9 / Blackwell).

What it does

  • Face swap with multiple swapper models and DeepFaceLab DFM support
  • Per-part masking, occlusion masking and face restoration
  • LivePortrait-based face editor (expression / pose, color adjustments)
  • Face embeddings, video markers and virtual-camera output

Requirements

  • Windows 10/11 (Linux too), recent NVIDIA driver
  • Python 3.11 (not 3.14), modern GPU (RTX 40/50, sm_90/sm_120)
  • ~15 GB disk for models and caches

Install

git clone https://github.com/lopatin2012/VisoMaster-Modern.git
cd VisoMaster-Modern
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements_cu129.txt
.venv\Scripts\python.exe download_models.py

Run

.venv\Scripts\python.exe main.py

or double-click Start.bat. Optional diagnostics: main.py --profile.
