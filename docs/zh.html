VisoMaster-Modern

基于 AI 的图片、视频和摄像头人脸替换与编辑。 VisoMaster 的社区分支，针对现代 NVIDIA 显卡（CUDA 12.9 / Blackwell）进行了现代化改造。

功能

  • 多种换脸模型，兼容 DeepFaceLab DFM
  • 按面部部件遮罩、遮挡遮罩与人脸修复
  • 基于 LivePortrait 的人脸编辑器（表情、姿势、颜色调整）
  • 人脸特征、视频标记与虚拟摄像头输出

要求

  • Windows 10/11（Linux 也可），较新的 NVIDIA 驱动
  • Python 3.11（不要用 3.14），现代 GPU（RTX 40/50，sm_90/sm_120）
  • 约 15 GB 磁盘空间用于模型和缓存

安装

git clone https://github.com/lopatin2012/VisoMaster-Modern.git
cd VisoMaster-Modern
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements_cu129.txt
.venv\Scripts\python.exe download_models.py

运行

.venv\Scripts\python.exe main.py

或双击 Start.bat。诊断：main.py --profile。
