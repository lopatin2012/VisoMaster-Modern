VisoMaster-Modern

Замена и редактирование лиц на изображениях, видео и в веб-камере с помощью ИИ. Форк VisoMaster, адаптированный под современные GPU NVIDIA (CUDA 12.9 / Blackwell).

Что это

  • Замена лиц с несколькими моделями сваппера и поддержкой DeepFaceLab DFM
  • Маскирование по частям лица, маска перекрытий и восстановление лиц
  • Редактор лица на базе LivePortrait (выражение, поза, коррекция цвета)
  • Эмбеддинги лиц, видео-маркеры и вывод в виртуальную камеру

Требования

  • Windows 10/11 (Linux тоже), актуальный драйвер NVIDIA
  • Python 3.11 (не 3.14), современный GPU (RTX 40/50, sm_90/sm_120)
  • ~15 ГБ на диске под модели и кэши

Установка

git clone https://github.com/lopatin2012/VisoMaster-Modern.git
cd VisoMaster-Modern
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements_cu129.txt
.venv\Scripts\python.exe download_models.py

Запуск

.venv\Scripts\python.exe main.py

или двойной клик по Start.bat. Диагностика: main.py --profile.
